1 Introduction

mfpi() assesses whether the effect of a grouping variable, such as treatment, varies with a continuous variable. The treatment effect is modelled as a fractional polynomial (FP) function of the continuous variable, so the variable does not need to be categorised. The procedure has two stages: Stage 1 selects an adjustment model with MFP, and Stage 2 tests each candidate interaction while holding that adjustment model fixed.

This vignette shows how to run the analyses in the accompanying paper (paper reference) and how to read the output. For the methodology, the flexibility variants (flex), the selection criteria and the interface, each section points to the relevant part of the paper (Sections 2 and 3).

library(mfp2)
library(survival)

2 Advanced prostate cancer data

The data come from a randomised trial comparing placebo with diethylstilboestrol (paper, Section 4). The outcome is overall survival (survtime, cens), and the grouping variable is the binary treatment rx. The data set already contains the recoding described in the paper.

Converting rx to a factor with named levels gives Placebo and Treatment labels in printed output, predictions and plots. The first level is the reference group (paper, Section 3.3).

data("advanced_prostate_cancer", package = "mfp2")
advanced_prostate_cancer$rx <- factor(
  advanced_prostate_cancer$rx,
  levels = c(0, 1), labels = c("Placebo", "Treatment")
)

table(advanced_prostate_cancer$rx)
#> 
#>   Placebo Treatment 
#>       237       238
tapply(advanced_prostate_cancer$age, advanced_prostate_cancer$rx, range)
#> $Placebo
#> [1] 48 84
#> 
#> $Treatment
#> [1] 49 89

The question is whether the treatment effect varies with age. The overall treatment comparison, which ignores age, shows no clear difference (paper, Section 4.1):

cox <- coxph(Surv(survtime, cens) ~ rx, data = advanced_prostate_cancer)

#>             exp(coef) exp(-coef) lower .95 upper .95
#> rxTreatment 0.8374787    1.19406 0.6762658  1.037123

The hazard ratio is 0.84 (95% CI 0.68–1.04). A single overall estimate like this can hide an effect that changes with age.

All analyses below use flex = "flex1" (the same FP powers in both groups) and ties = "breslow", as in the paper. The package defaults are flex = "flex3" and ties = "efron". The paper (Sections 2.5 and 4) explains both choices and how Efron’s method changes the results.

What the arguments do:

  • fp(age) puts age in the Stage 1 adjustment model. It does not set the form of the interaction.
  • group_var names the grouping variable.
  • interaction_vars lists the continuous variables tested for interaction with group_var.
  • interaction_forms = c(age = "fp2") models the interaction with an FP2 function. All 36 FP2 power pairs are compared. Variables not listed use FP1.
  • flex = "flex1" selects the FP powers from the model without interaction and uses them in both groups (paper, Section 2.5).

How to read the output (paper, Section 4.2):

  • Step 1 is the adjustment model. Age is selected as FP1 with power 3. Here age is the only adjustment variable, and it is removed from the adjustment set when its own interaction is tested.
  • Step 2 is the interaction test. The FP2 powers (3, 3) are used in both groups. Adding the interaction reduces the deviance by 9.746 on 2 df.
  • Step 3 summarises the decision: the interaction is selected (p = 0.008).

3.1 Plotting the interaction

plot() returns a list with one element per variable. Each element contains one plot per comparison with the reference group.

p_unadj <- plot(fit_unadjusted, terms = "age", plot_type = "both",
                show_title = FALSE)

Unadjusted analysis: fitted age functions by group (left) and the Treatment-minus-Placebo log hazard ratio with 95% CI (right); paper, Figure 2.

The right panel shows the log hazard ratio for Treatment vs Placebo as a function of age, the difference function \(\Delta\) (paper, Section 2.3). The dashed line is the constant log hazard ratio from the model without interaction. Here, the benefit of treatment is largest in younger patients and decreases with age. The confidence intervals do not account for the selection of FP powers.

5 Selection with AIC

With criterion = "aic", AIC is used in both stages. The interaction is selected when it lowers AIC by more than min_improvement (default 2). criterion = "bic" works the same way (paper, Section 2.6).

  data = advanced_prostate_cancer,

7 Fixed linear adjustment model

The adjustment model can be prespecified instead of selected:

  • fp(x, df = 1) gives a linear adjustment effect, with no FP power search.
  • keep forces the named variables into the adjustment model.
fit_fixed_linear <- mfpi(
  Surv(survtime, cens) ~
    rx +
    fp(age, df = 1) + fp(wt, df = 1) + fp(sbp, df = 1) +
    fp(dbp, df = 1) + fp(sz, df = 1) + fp(ap, df = 1) +
    fp(hg, df = 1) + fp(sg, df = 1) +
    pf + hx + bm + stage + ekg,
  data = advanced_prostate_cancer,
  family = "cox",
  group_var = "rx",
  interaction_vars = "age",
  interaction_forms = c(age = "fp2"),
  flex = "flex1",
  ties = "breslow",
  criterion = "pvalue",
  keep = c("age", "wt", "sbp", "dbp", "sz", "ap", "hg", "sg",
           "pf", "hx", "bm", "stage", "ekg")
)

fp(age, df = 1) affects only the adjustment model. The interaction with treatment is still FP2, as set by interaction_forms. To use a known transformation in the adjustment model (for example, log(x)), create the transformed variable first and enter it with df = 1 (paper, Section 4.6).

8 More than two groups

group_var may have more than two levels. Each non-reference group is compared with the reference group, and plot() and predict() return one comparison per non-reference group (paper, Section 4.7).

9 The xy interface

mfpi() also accepts a predictor data frame x and a response y instead of a formula. Columns are matched by name, so their order does not matter (paper, Appendix A).

y <- with(advanced_prostate_cancer, Surv(survtime, cens))
x <- advanced_prostate_cancer[, c(
  "rx", "age", "wt", "sbp", "dbp", "sz", "ap", "hg", "sg",
  "pf", "hx", "bm", "stage", "ekg"
)]

Passing all columns of x makes every other variable a candidate for the adjustment model. The following calls give the same results as the adjusted, AIC and multiple-candidate formula fits above:

fit_adjusted_xy <- mfpi(
  x = x, y = y, family = "cox",
  group_var = "rx", interaction_vars = "age",
  interaction_forms = c(age = "fp2"), flex = "flex1", ties = "breslow"
)

fit_aic_xy <- mfpi(
  x = x, y = y, family = "cox",
  group_var = "rx", interaction_vars = "age",
  interaction_forms = c(age = "fp2"), flex = "flex1", ties = "breslow",
  criterion = "aic", min_improvement = 2
)

fit_multiple_xy <- mfpi(
  x = x, y = y, family = "cox",
  group_var = "rx",
  interaction_vars = c("age", "wt", "sbp", "dbp", "sz", "ap", "hg"),
  interaction_forms = c(age = "fp2"), flex = "flex1", ties = "breslow",
  p_adjust_method = "holm", verbose = FALSE
)

Without a formula, settings that fp() would set are given as named vectors. For the fixed linear adjustment model, df sets each continuous variable to linear and keep forces all variables in:

fit_fixed_linear_xy <- mfpi(
  x = x, y = y, family = "cox",
  group_var = "rx", interaction_vars = "age",
  interaction_forms = c(age = "fp2"), flex = "flex1", ties = "breslow",
  criterion = "pvalue",
  df = c(age = 1, wt = 1, sbp = 1, dbp = 1,
         sz = 1, ap = 1, hg = 1, sg = 1),
  keep = c("age", "wt", "sbp", "dbp", "sz", "ap", "hg", "sg",
           "pf", "hx", "bm", "stage", "ekg")
)

Centering (center, center_type) works the same in both interfaces. It does not change the fitted values, the difference function, the selected powers or the p-values (paper, Appendix A.7).
